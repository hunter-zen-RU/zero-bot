# Known Bugs & Roadmap

This page tracks known issues, pending features, and planned improvements.

---

## Known Issues

The following issues are acknowledged and under investigation:

- **Show all messages**  
  Some message types may not be displayed correctly in certain UI views.

- **UI customization limitations**  
  Not all UI elements are currently themeable or configurable.

- **Packet capture functionality**  
  Packet capture features are incomplete or unstable in some variants.

- **Verbose logging robustness**  
  Verbose/debug modes may produce inconsistent output or miss some events.

- **API center stability**  
  The API center module may experience intermittent issues under heavy load.

Workarounds and fixes will be added as they become available.

---

## Pending Features

Planned or in-progress features include:

- Full “show all messages” support across all views
- Advanced UI customization (themes, layouts, per-user preferences)
- Stable packet capture and analysis tools
- Improved verbose/debug logging with structured output
- Hardened and documented API center

---

## Variants Under Development

These variants are actively being developed and may change significantly:

Feature lists and version pages will be expanded as these reach stable status.
