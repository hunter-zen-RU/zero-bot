## v4.0.0-modular

**Version:** `4.0.0`  
**Variant:** Modular  
**Status:** Stable (recommended)

### Overview

`v4.0.0-modular` is the primary stable release. It includes:

- Full command set for group and chat management
- Modular file layout for easy extension
- Compatibility with the official `v4.1.0-pro` patch (optional)

## v4.0.0-dragon & v4.0.0-dragon-v2

**Version:** `4.0.0`  
**Variants:** Dragon, Dragon-v2  
**Status:** Stable (specialized use cases)

### Overview

The Dragon family targets advanced users who need:

- Session folder management (Dragon)
- AI integrations and Telegram support (Dragon-v2)

See [Features by Version](FEATURES.md#v400-dragon) for a feature breakdown.
